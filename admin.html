🔐 Connexion admin

Cette page modifie directement le fichier products.json de votre dépôt GitHub. Rien n'est envoyé ailleurs qu'à GitHub, et votre jeton reste uniquement dans ce navigateur (il n'est jamais sauvegardé dans le code du site).

Comment créer ce jeton (une seule fois, 2 minutes) ?
1. Allez sur github.com/settings/tokens (connecté à votre compte GitHub).
2. Cliquez « Generate new token » → « Fine-grained token ».
3. Dans « Repository access », choisissez « Only select repositories » et sélectionnez ce dépôt.
4. Dans « Permissions » → « Contents », choisissez « Read and write ».
5. Générez, copiez le jeton (il commence par github_pat_) et collez-le ci-dessus.
6. Gardez-le secret — quiconque le possède peut modifier ce fichier sur votre dépôt.
